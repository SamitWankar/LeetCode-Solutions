# 0025 - Reverse Nodes in K-Group

## Problem

Given the head of a linked list and an integer `k`, reverse the nodes of the list `k` nodes at a time.

If the number of remaining nodes is less than `k`, those nodes should remain unchanged.

You must solve the problem by modifying the links between nodes.

## Example

Input:

```text
head = [1,2,3,4,5], k = 2
