# LeetCode 23 - Merge k Sorted Lists

## Problem

You are given an array of `k` linked lists, where each linked list is sorted in ascending order.

Merge all the linked lists into one sorted linked list and return it.

## Example

### Input

```text
lists = [
    1 → 4 → 5,
    1 → 3 → 4,
    2 → 6
]
