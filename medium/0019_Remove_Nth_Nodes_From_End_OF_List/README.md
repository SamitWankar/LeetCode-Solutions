# 0019 - Remove Nth Node From End of List

LeetCode Problem 19.

## Problem

Remove the nth node from the end of a singly linked list and return the modified list.

## Example

Input:

head = [1,2,3,4,5]
n = 2

Output:

[1,2,3,5]

## Technique

Two Pointers / Fast and Slow Pointers

## Complexity

- Time: O(n)
- Space: O(1)
