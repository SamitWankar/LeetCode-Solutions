# Explanation - LeetCode 22: Generate Parentheses

## 1. Problem Understanding

We are given an integer `n` representing the number of pairs of parentheses.

We need to generate all possible combinations of parentheses that are **well-formed**.

For example:

```text
Input:
n = 3

Output:
["((()))", "(()())", "(())()", "()(())", "()()()"]
