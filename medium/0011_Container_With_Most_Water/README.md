# LeetCode 11 — Container With Most Water

**Difficulty:** Medium

**Topic:** Array, Two Pointers

## Description

Find two vertical lines that form a container capable of holding the maximum amount of water.

## Solution

This problem is solved using the **Two Pointer** technique.

The two pointers start at opposite ends of the array. At each step, we calculate the area and move the pointer corresponding to the shorter line.

## Complexity

* **Time:** O(n)
* **Space:** O(1)
